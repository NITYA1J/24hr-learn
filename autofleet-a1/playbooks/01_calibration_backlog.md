# Sensor calibration backlog
Use when: sensor_calibration is the top cause of downtime or readiness points lost.
Actions: 1) Add a dedicated calibration bay and certified calibration targets at the worst site. 2) Batch calibrations into a scheduled rolling window so techs avoid setup switching. 3) Track second-attempt rate; repeat calibrations above 15% point to tooling or bracket faults, not technique. 4) Pre-stage lidar and camera spares so a failed calibration does not become a parts wait. 5) Review whether OTA software updates trigger avoidable recalibrations.
Owner: Site service manager. Review: weekly.
