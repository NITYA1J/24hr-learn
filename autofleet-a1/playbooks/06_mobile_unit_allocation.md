# Mobile unit allocation
Use when: bays are saturated or a site has a long queue of simple jobs.
Actions: 1) Send mobile units to tires, software and minor sensor jobs that need no bay lift. 2) Move units from healthy sites to the site with the largest readiness gap. 3) Schedule units by queue age, oldest first. 4) Stock mobile units with the top five fast-moving parts. 5) Measure queue time before and after the reallocation.
Owner: Regional operations lead. Review: weekly.
