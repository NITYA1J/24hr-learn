# Night-shift staffing gap
Use when: one site has far fewer night technicians, high work orders per night tech-shift, or night-opened orders age longer.
Actions: 1) Compare night tech count and WOs per tech-shift with peer sites; target parity. 2) Add or rotate technicians onto nights, using a shift differential if needed. 3) Use remote triage so night techs start work with the right parts. 4) Defer non-urgent day-class jobs to the day shift. 5) Review after two weeks using backlog aging and night cycle time.
Owner: Regional operations lead. Review: weekly.
