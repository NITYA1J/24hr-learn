# Repeat failures on one category
Use when: the same vehicle or category fails again within 14 days.
Actions: 1) Flag vehicles with two or more same-category orders in 14 days. 2) Hold repeat repairs for senior technician sign-off. 3) Check part batch and supplier for the repeat window. 4) Add a verification test drive before release. 5) Feed confirmed root causes back into the service bulletin.
Owner: Quality lead. Review: weekly.
