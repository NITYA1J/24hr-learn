# Declining regional readiness
Use when: a region readiness slope is clearly negative across weeks.
Actions: 1) Break the decline down by site and category to find what is growing. 2) Check whether work order intake is rising (fleet age, new route load) or repairs are slowing. 3) Add temporary capacity to the region while the cause is found. 4) Pull forward preventive maintenance for the fastest-growing failure category. 5) Set a weekly readiness floor trigger that escalates to the regional lead.
Owner: Regional operations lead. Review: weekly.
